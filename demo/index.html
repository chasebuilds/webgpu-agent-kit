webgpu-agent-kit

WebGPU examples that AI coding agents can look up, copy and check.

WebGPU lets a web page use the graphics card for 3D scenes and heavy math. It is easy for an AI assistant to get wrong. This kit gives the assistant tested examples, a checker that catches shader mistakes, and short notes on the tricky parts. Every example below is running live in your browser right now.

Use it with your coding agent

From a terminal

npx github:chasebuilds/webgpu-agent-kit examples search particles
npx github:chasebuilds/webgpu-agent-kit examples pull compute-boids ./boids
npx github:chasebuilds/webgpu-agent-kit check shader.wgsl
npx github:chasebuilds/webgpu-agent-kit docs buffers

Needs Node 24.12 or newer.

As an MCP server

Works in Claude Code, Cursor and other MCP clients. Add this to the client's MCP settings:

{
  "mcpServers": {
    "webgpu-agent-kit": {
      "command": "npx",
      "args": ["-y", "github:chasebuilds/webgpu-agent-kit", "mcp"]
    }
  }
}
